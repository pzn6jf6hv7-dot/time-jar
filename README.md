# 🫙 时间储蓄罐 · Time Jar

> 把时间存进罐子，看着植物慢慢长大 🌱

时间储蓄罐是一款基于浏览器的本地时间追踪应用。它融合了**番茄钟**、**时间记录**和**植物养成**的游戏化机制——每当你投入时间，罐子里的植物就会成长，最终开花结果。

## ✨ 核心功能

- 🍅 **番茄钟 + 手动记录** — 两种模式随心切换，记录每一份专注
- 🌱 **植物成长系统** — 6 个成长阶段，用 Canvas 绘制动画
- 🫙 **四种罐子容量** — 10 / 100 / 1000 / 10000 小时，适合不同目标
- 👤 **多用户支持** — 每个用户独立存储数据，互不干扰
- 📊 **数据统计** — 日/周趋势图、罐子排名、连续天数
- 💾 **导入导出** — JSON 格式备份，数据永远在你手里
- 📱 **响应式设计** — 手机和电脑都好看
- 🔒 **纯本地存储** — 数据存在浏览器 localStorage，不上传任何服务器

## 🚀 快速开始

### 直接使用（推荐）

1. 下载 `index.html`
2. 用浏览器打开即可

就一步，没有依赖，没有构建，开箱即用。

## 📝 使用说明

1. **注册/登录** — 首次使用需创建账户（数据存储在浏览器本地）
2. **创建罐子** — 设定名称、目标时长、罐子大小和植物类型
3. **记录时间** — 可以用番茄钟专注计时，也可以手动填写
4. **查看花园** — 植物会根据投入时间自动成长
5. **统计页面** — 查看你的时间分布和趋势
