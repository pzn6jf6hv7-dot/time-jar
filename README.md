# 🫙 时间储蓄罐 · Time Jar

> 把时间存进罐子，看着植物慢慢长大 🌱

时间储蓄罐是一款桌面时间追踪应用，融合了**番茄钟**、**时间记录**和**植物养成**的游戏化机制。现已支持 Windows 桌面版！

## 📥 下载安装

### Windows 桌面版（推荐）

前往 [Releases](https://github.com/pzn6jf6hv7-dot/time-jar/releases) 页面下载最新版 `时间储蓄罐-Setup-1.0.0.exe`：

1. 下载安装程序
2. 双击运行，按提示安装
3. 桌面和开始菜单会自动创建快捷方式
4. 数据保存在本地，完全离线可用

### 浏览器版

如果你不想安装，也可以直接在浏览器中使用：

1. 下载 `index.html`
2. 用浏览器打开即可，无需任何依赖

## ✨ 核心功能

- 🍅 **番茄钟 + 手动记录** — 两种模式随心切换，记录每一份专注
- 🌱 **植物成长系统** — 6 个成长阶段，Canvas 绘制动画
- 🫙 **四种罐子容量** — 10 / 100 / 1000 / 10000 小时，适合不同目标
- 👤 **多用户支持** — 每个用户独立存储数据，互不干扰
- 📊 **数据统计** — 日/周趋势图、罐子排名、连续天数
- 💾 **导入导出** — JSON 格式备份，数据永远在你手里
- 📱 **响应式设计** — 手机和电脑都好看
- 🔒 **纯本地存储** — 数据不上传任何服务器，隐私安全

## 🛠 技术栈

| 技术 | 用途 |
|------|------|
| Electron | 桌面应用框架 |
| React 18 | UI 框架 |
| Chart.js | 数据统计图表 |
| Canvas API | 植物绘制动画 |
| localStorage | 数据持久化 |

## 📝 使用说明

1. **注册/登录** — 首次使用需创建账户（数据存储在本地）
2. **创建罐子** — 设定名称、目标时长、罐子大小和植物类型
3. **记录时间** — 可以用番茄钟专注计时，也可以手动填写
4. **查看花园** — 植物会根据投入时间自动成长
5. **统计页面** — 查看你的时间分布和趋势

## 🎨 设计风格

清新可爱的粉色系 UI，搭配毛玻璃效果和浮动动画装饰。
